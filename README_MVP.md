# PropertyAI.kz — MVP

## Цель
Сервис для риэлторов, который автоматически обрабатывает входящие сообщения в WhatsApp, квалифицирует клиента и передаёт готовый лид специалисту.

Главная задача:
не отвечать “умно”, а доводить до контакта (имя + телефон).

## Основной сценарий
1. Клиент пишет в WhatsApp
2. Бот отвечает и задаёт уточняющие вопросы
3. Собирает:
   - тип запроса
   - тип объекта
   - район
   - комнаты
   - бюджет
   - цель
   - имя
   - телефон
4. После этого создаётся лид
5. Риэлтор получает уведомление
6. Риэлтор берёт диалог и работает дальше

## Правила MVP
1. Если чат новый — бот отвечает
2. Если лид квалифицирован — бот пишет финальное сообщение и ждёт
3. Если риэлтор нажал “взять чат” — бот больше не отвечает
4. Если бот глобально выключен — не отвечает никому

## Что не входит в MVP
- RAG
- PDF
- парсинг Krisha
- сложные AI-агенты
- drag-and-drop сценарии
- мобильное приложение
- автоматический подбор объектов
